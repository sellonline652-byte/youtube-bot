Privacy Policy - My Uploader

Last updated: 25 October 2026

My Uploader is used only by the owner of the YouTube channel Sujay Ganguly Creations to manage that channel.

Data we access

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload the channel's own videos, set titles, descriptions and thumbnails, manage the channel's playlists, reply to comments on the channel's videos and read the channel's own analytics.

How data is used and stored

Data is used only to run the owner's channel. Login tokens are stored encrypted and are never shared or sold. No data from other users is collected. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at https://myaccount.google.com/permissions.
